# EarlySteps – Frontend

## About the Project

EarlySteps is a web-based educational platform designed to support children's learning and development through interactive activities, assessments, and educational games.

The platform provides different interfaces and features for parents, teachers, and administrators to manage and follow children's learning progress.

## Features

- User authentication and account management.
- Role-based access for different users.
- Children's learning progress tracking.
- Interactive educational games and tests.
- Teacher activities, notes, and communication.
- Content and user management.

## Technologies Used

- React 19
- TypeScript
- Vite
- React Router
- TanStack Query
- Axios
- Zustand
- React Hook Form
- Zod
- CSS Modules

## Installation and Setup

1. Clone the repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Project Structure

The project is organized into components, pages, services, and configuration files to maintain a clean and organized codebase.
